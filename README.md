PROJECT NAME: EduBooks - Online Book Platform
==================================================

1. DETAILS
------------------
Name: [W M R Y Bandara]

2. PROJECT OVERVIEW
-------------------
EduBooks is a responsive learning platform designed for students to explore academic books and educational resources. The interface features a dark nature/forest theme created using HTML5, CSS3, and JavaScript.


3. TECHNOLOGIES USED
--------------------
- HTML5 (Semantic Structure)
- CSS3 (Flexbox, Grid, Responsive Layout)
- JavaScript (DOM Manipulation, Interactive Search, Form Validation)
- Font Awesome Icons (Visual Icons)


4. KEY FEATURES IMPLEMENTED
---------------------------
- Header & Navigation Bar (Logo, Quick Links, Search Bar)
- Hero Section (Call to Action Button)
- Features Grid (Card Layout with Icons)
- Featured Books Section (Interactive Search & Filter Functionality)
- Newsletter Section (Email Input with JavaScript Validation)
- Responsive Footer (Social Links, Quick Navigation, Legal Notes)
- Fully Responsive Design (Desktop, Tablet, Mobile)
